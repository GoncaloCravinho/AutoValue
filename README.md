# AutoValue

AutoValue is a web development project focused on estimating the market value of used cars.

The project is being developed as part of the Web Development course of the Bachelor's Degree in Data Science for Management at Coimbra Business School | ISCAC.

## Project

The application will allow users to enter the main characteristics of a vehicle and obtain an estimated market value.

The planned website includes:

- Home
- Estimate
- Market Insights
- Feature Importance
- About

## Technologies

The project will use HTML, CSS and JavaScript, together with a Machine Learning model for vehicle price estimation.
